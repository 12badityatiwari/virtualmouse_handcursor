# virtualmouse_handcursor
Virtual Mouse – Hand Cursor
Virtual Mouse – Hand Cursor is a computer vision based project that allows users to control the
mouse cursor using hand gestures captured through a webcam. This project demonstrates
touch-free human–computer interaction using AI and real-time hand tracking.
Project Overview
The system tracks hand landmarks using a live camera feed and converts hand movement into
mouse cursor movement on the screen. It eliminates the need for physical mouse interaction.
How It Works
• Webcam captures live video
• Hand landmarks are detected using MediaPipe
• Hand movement is analyzed frame by frame
• Cursor position is updated in real time
• Smooth motion is applied for better control
Technologies Used
• Python
• OpenCV
• MediaPipe Hands
• PyAutoGUI
• NumPy
System Requirements
• Python 3.8 or above
• Working webcam
• Windows / Linux / macOS
How to Run
1. Install required libraries
2. Run the Python script
3. Allow camera access
4. Use hand movement to control cursor
Usage Instructions
• Keep your hand clearly visible to the camera
• Move hand to control cursor direction
• Proper lighting improves accuracy
Applications
• Virtual mouse systems
• Accessibility support
• AI and computer vision learning
• Gesture-based control systems
Limitations
• Performance depends on lighting
• Fast hand movements may reduce accuracy
• Clicking features may require extension
